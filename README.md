# 桌面宠物 Desktop Pet

一个运行在 Windows 桌面上的小宠物程序，灵感来自早年的 QQ 宠物。宠物会在桌面底部漫步、说话、互动，支持多屏幕、多宠物同时运行。

---

## 功能特性

- **桌面漫游** — 宠物在屏幕底部自由走动，带倾斜 / 呼吸动画
- **拖拽 & 重力** — 拖起后松手会自由落体落回桌面
- **跨屏返回** — 被拖到其他屏幕后加速跑回自己的指定屏幕
- **时间感知** — 早晨问好、深夜进入睡眠（旋转 90° + Zzz 气泡）
- **对话气泡** — 点击宠物弹出个性化对话，猫猫 / 狗狗语言库分开
- **宠物互动** — 多只宠物通过文件 IPC 感知彼此，凑近时触发互动台词
- **多屏幕支持** — 可为每只宠物指定显示器（屏幕 1 / 2 / 3）
- **右键菜单** — 深色风格，支持切换屏幕、调整大小、新增宠物
- **图片去背** — 用 `rembg` 从真实照片一键去除背景，生成透明 PNG
- **深色启动器** — Apple 风格深色 GUI，管理所有宠物、支持批量启动

## 环境要求

| 项目 | 版本 |
|------|------|
| Python | 3.10 ~ 3.13 |
| 操作系统 | Windows 10 / 11 |
| PyQt5 | >= 5.15 |

> **注意**：不支持 PyQt6（Python 3.13 下存在 DLL 加载失败问题）。

## 安装

```bash
# 1. 克隆仓库
git clone <your-repo-url>
cd desktop_pet

# 2. 安装依赖
pip install -r requirements.txt
```

`rembg` 首次运行时会自动下载 AI 模型（约 170 MB），需要联网。

## 快速开始

### 方式一：双击桌面快捷方式（推荐）

运行一次下面的命令创建快捷方式，之后双击 `PetLauncher` 图标即可：

```bash
python create_shortcut.py
```

> 快捷方式会放在桌面，指向 `pythonw.exe launcher.py`，无黑窗口静默启动。

### 方式二：命令行直接启动

```bash
# 启动启动器 GUI
python launcher.py

# 或直接启动单只宠物
python main.py pet.png 0 dog 100 嘟嘟
#               图片    屏幕 类型 大小 名字
```

## 文件结构

```
desktop_pet/
├── launcher.py          # 深色 GUI 启动器（管理所有宠物）

├── create_pet.py        # 生成占位宠物图片（Pillow）
├── requirements.txt
└── *.png                # 宠物图片（透明背景 PNG）
```

## 宠物配置（pets.json）

```json
{
  "pets": [
    {
      "name": "嘟嘟",
      "image": "pet.png",
      "screen": 0,
      "type": "dog",
      "size": 100,
      "enabled": true
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `name` | 宠物名字，出现在对话气泡中 |
| `image` | 图片路径（PNG，建议透明背景） |
| `screen` | 指定屏幕编号，从 0 开始 |
| `type` | `dog` / `cat` / `generic`，决定使用哪套语言库 |
| `size` | 宠物大小（像素），推荐 60 ~ 200 |
| `enabled` | 是否在启动时加载 |

## 制作自己的宠物图片

**方法 A：用真实照片（自动去背景）**

```bash
python make_pet_from_photo.py 我的猫.jpg my_cat.png
```

首次运行会下载 `u2net` 模型，之后离线可用。

**方法 B：手动准备 PNG**

- 尺寸建议：200×200 ~ 400×400 px
- 必须是透明背景（RGBA 模式）
- 放入项目目录，在启动器中点击「添加宠物」选择即可

## 宠物行为说明

| 状态 | 触发条件 |
|------|---------|
| 漫步 | 随机间隔左右行走，附带倾斜动画 |
| 待机 | 静止时轻微呼吸缩放 |
| 拖拽 | 鼠标左键按住拖动 |
| 掉落 | 松手后重力加速下落至屏幕底部 |
| 返回 | 落到错误屏幕后，加速跑回指定屏幕 |
| 问候 | 早晨 6~9 点触发，弹出早安气泡 |
| 睡眠 | 凌晨 0~6 点旋转 90°，显示 Zzz |
| 互动 | 两只宠物距离 < 150px 时互相说话 |
